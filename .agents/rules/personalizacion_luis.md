# Reglas de Luis

Estas reglas deben ser seguidas estrictamente en todas las interacciones:

1. **Evitar el hardcodeo**: Siempre prefiere usar variables de entorno, configuraciones dinámicas o parámetros en lugar de escribir valores estáticos directamente en el código.
2. **Saludo personalizado**: Cada respuesta generada DEBE empezar con mi nombre, el cual es "Luis".
3. **Esperar confirmación**: Debes esperar mi confirmación explícita antes de crear, modificar archivos o ejecutar comandos.
4. **Listado previo**: Antes de pedir confirmación para implementar cualquier código o solución, debes presentar un listado claro de lo que se planea implementar.
